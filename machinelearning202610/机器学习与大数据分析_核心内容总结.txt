■ 两条主线任务

      回归预测：输出变量为数值型
      分类预测：输出变量为分类型（二分类 / 多分类）
  (2) 数据聚类（无监督学习）——第 11~12 章
      发现数据中客观存在的"自然小类"，刻画数据内在组织结构

■ 贯穿全书的五个核心论点（最重要的思想）

  论点 1：机器学习是"基于数据建模"的新编程范式
    经典程序设计：人总结规则 → 输入数据 → 计算机给出答案
    机器学习范式：输入数据 + 答案 → 计算机自动学出规则
    本质是：基于巨量数据集，发现其中隐藏的、有效的、可理解的规则。
    AI 发展三阶段：符号主义 AI → 机器学习 → 深度学习（2006年突破）
    深度学习 = 从数据中学习"数据表示"，机器学习相对称为"浅层学习"。

  论点 2：训练误差最小化 ≠ 模型最优，泛化能力才是终极目标  ★核心
    模型误差   ：基于训练集（"袋内观测"）计算的误差
    泛化误差   ：模型在新数据集（"袋外观测" OOB）上的误差，无法直接计算
    关键结论   ：训练误差是对泛化误差的**偏低估计**
                 训练误差最小时，测试误差不一定最小
                 理想模型 = 泛化误差（测试误差）最小的模型
    必须用测试误差来估计泛化误差。

  论点 3：模型复杂度是一把双刃剑——偏差与方差的权衡  ★核心
    偏差（Bias）  ：多个预测值的期望与实际值的差 → 度量"准不准"
    方差（Var）   ：多个预测值自身的波动程度     → 度量"稳不稳"
    偏差-方差分解：
        泛化误差 = 偏差²  +  方差  +  随机误差项方差
        Err(x0)  = [Bias(ŷ0)]² + Var(ŷ0) + Var(ε)
    规律：模型复杂度↑ → 偏差↓ 但 方差↑
          若偏差减少能抵消方差增加 → 泛化误差继续下降
          若无法抵消               → 泛化误差上升（进入过拟合区）
    第三项（随机误差）永远存在，无法消除。

  论点 4：模型选择遵循"奥卡姆剃刀"原则
    在训练误差可接受的前提下，选择**更简单**的模型。
    简单模型训练误差通常高于复杂模型，但若其泛化误差更低，则应选简单模型。
    优秀模型两个特征：① 训练误差在可接受范围 ② 具有预测稳健性
    过度复杂的后果：① 过拟合导致高泛化误差 ② 过拟合导致低稳健性

  论点 5："弱模型联合成强模型"是提升预测性能的有效路径
    集成学习的两大流派：
      · 并行派（降低方差）：Bagging、随机森林 —— 基础学习器彼此独立
      · 串行派（降低偏差）：AdaBoost、GBDT、XGBoost —— 基础学习器顺序相关
    哲学："三个臭皮匠顶上一个诸葛亮"。

第 02 章  数据预测中的相关问题  (P19-P45)  ★全书理论基石
================================================================================

■ 本章地位：最重要的方法论章节。后续所有模型都依赖本章的
  "建模—评价—选择"框架。务必吃透。

■ 2.1 预测建模
  预测模型定义：以数学形式精确刻画输入变量 X 与输出变量 y 的数量关系

  回归预测模型（数值型输出）：
      y = β0 + β1*X1 + β2*X2 + ... + βp*Xp + ε
      预测方程：ŷ = β̂0 + β̂1*X1 + ... + β̂p*Xp
  分类预测模型（分类型输出，以二分类 Logistic 为例）：
      log( P / (1-P) ) = β0 + β1*X1 + ... + βp*Xp + ε
      预测：Logit(P̂) = β̂0 + β̂1*X1 + ... + β̂p*Xp
  其他形式：推理规则（逻辑判断形式），可图形化展示

  几何理解  ★重要的直观工具
    N 个样本观测 = p 维实数空间 R^p 中的 N 个点
    回归：回归直线 / 回归平面（从直线到曲线，从平面到曲面）
    分类：分类直线 / 分类平面

■ 2.2 参数估计
  两条基本策略：
    ① 以损失函数最小为目标（有监督学习）
    ② 借助特定搜索策略在"参数解空间"中搜索

  常用损失函数（务必记住对应关系）：
    回归 —— 平方损失：  L(y, ŷ) = (y - ŷ)²
    分类 —— 交互熵：    L(y, P̂k(x)) = -Σ I(y=k) * log P̂k(x) = -log P̂y(x)
    二项偏差损失：      L = -y*f̂(x) + log(1 + exp(f̂(x)))
    指数损失：          L(y, f̂(x)) = exp(-y * f̂(x))
    多分类损失（Softmax 形式）：
        L = -Σ I(y=k) * log[ exp(f̂k(x)) / Σ exp(f̂l(x)) ]

  最小二乘估计（OLS）
    对平方损失求和并对各 β 求偏导令其为 0，得到正规方程组。
    适用条件（三个前提）：
      ① N ≥ p + 1（样本量不小于参数个数）
      ② 输入与输出呈线性关系假设
      ③ 损失函数是参数的二次函数 → 要求模型为线性模型
  梯度下降法：当无法得到闭式解时，在解空间中迭代搜索参数。

■ 2.3 模型评价  ★核心考点
  两个易混淆概念：
    模型误差：对已有数据集上预测值与实际值不一致程度的度量
    泛化误差：对新数据集预测的误差，测度模型在未来场景的普适性与推广性

  误差评价指标：
    回归 —— 均方误差：MSE = (1/N) * Σ (yi - ŷi)² = E[ L(yi, f̂(xi)) ]
    二分类 —— 准确率、精确率、召回率、F1 分数
    多分类 —— 微平均（Micro-averaged）/ 宏平均（Macro-averaged，如宏F1）

  图形化评价工具：
    ROC 曲线与 AUC 值
    P-R 曲线（精确率-召回率曲线）

  泛化误差的估计（关键推理链）：
    训练集（袋内观测）→ 训练误差 / 经验误差
    测试集（袋外观测 OOB）→ 测试误差 → 作为泛化误差的估计
    理论泛化误差：Err = E[ Err_T ]（对所有可能训练集 T 的平均）

  训练误差与测试误差关系的三条结论  ★★
    ① 训练误差是对泛化误差的偏低估计 → 应采用测试误差估计泛化误差
    ② 训练误差最小时测试误差不一定最小 → 训练误差最小的模型泛化能力不一定最强
    ③ 理想模型 = 泛化能力最强 = 测试误差最小的模型

  数据集划分策略（三种）：
    旁置法（Hold out）    ：随机划分为训练集 / 测试集两部分
    留一法（LOO）         ：N-1 个训练，1 个测试，重复 N 次
    K 折交叉验证（CV）★  ：随机等分为不相交的 K 份，每次 K-1 份训练、
                            1 份测试，共 K 次，取平均。最常用。
    交叉验证误差：CV(f̂, α) = (1/N_test) * Σ L(yi, f̂^(-k(i))(xi, α))

■ 2.4 模型选择
  理论依据：奥卡姆剃刀（Occam's Razor）原则
  过拟合（Over-Fitting）定义：
    在训练误差最小原则下，模型远远偏离输入输出的真实关系，
    导致在新数据集上有较大预测误差的现象。
    典型表现：训练误差小，但测试误差大。
  偏差与方差（定义见第 00 部分）
    偏差小 → 模型准，泛化误差小
    方差小 → 模型稳健（鲁棒），泛化误差估计可靠

■ 本章实践：空气污染分类预测
    建立 Logistic 回归模型 → 优化模型 → 评价

第 03 章  数据预测建模：贝叶斯分类器  (P46-P57)
================================================================================

■ 核心思想：基于贝叶斯定理，用"最大后验概率"做分类决策

■ 贝叶斯概率与贝叶斯法则
  贝叶斯概率：对某事物发生概率的**信任程度**，是一种主观概率。
              取决于先验认知 + 新信息加入后的不断修正。
  贝叶斯法则：
      P(yi | X) = P(yi) * P(X | yi) / P(X)
                = P(yi) * P(X | yi) / Σ P(yi) * P(X | yi)
  三个要素：先验概率 P(yi)、数据似然 P(X|yi)、后验概率 P(yi|X)

■ 贝叶斯分类器
  决策原则：最大后验概率估计
      arg max_y P(y = yi | X)
  关键简化：后验概率**正比于分子**
      P(y=yi | X) ∝ P(y=yi) * P(X | yi)
      → 只需计算和比较分子大小即可决策（分母对所有类相同）

  朴素贝叶斯分类器  ★
    核心假设：给定输出变量条件下，各输入变量**条件独立**
        P(X1, X2 | yi) = P(X1 | yi) * P(X2 | yi)
    高斯朴素贝叶斯：数值型输入变量的数据似然采用高斯密度函数
        f(X | y=yi) = 1/(√(2π)σ) * exp( -(X - X̄)² / (2σ²) )
    评价：尽管条件独立假设未必合理，但在文本分类等大量场景中表现良好。

■ 先验分布进阶
  共轭先验：若后验分布 π(θ|D) 与先验分布 π(θ) 数学形式相同（同属一族分布），
            则二者互为共轭分布，π(θ) 是似然函数的共轭先验。
      好处：代数方便，可直接给出后验的闭式解，直观展现数据对先验的修正。
      后验：π(θ|D) = f(D|θ) * π(θ) / ∫ f(D|θ) * π(θ) dθ
      经典例子：Beta 先验 + 二项似然 → Beta 后验
          π(θ) ~ Beta(a, b)
          f(D|θ) ∝ θ^n1 * (1-θ)^n2
          π(θ|D) ~ Beta(n1 + a, n2 + b)
  无信息先验：依据样本分布原则 / 熵值最大法原则
      信息熵（香农 1948）：Ent(U) = -Σ P(ui) * log2 P(ui)
      熵为非负数；熵越大平均不确定性越大
      等概率时熵最大；唯一确定时熵为 0

■ 本章实践（两个应用案例）
  ① 空气质量等级的贝叶斯分类
  ② 法律裁判文书的案情要素分类（文本分类，2665 条婚姻家庭裁判文书）
     文本量化处理关键：分词 + TF-IDF
       TF（词频）  = Nji / Σ Njk
       IDF（逆文本频率）= log( 总文本数 / 包含词 i 的文本数 )
       TF-IDF(ji) = TF(ji) × IDF(i)
       TF-IDF 越大，词 i 对文本 j 越重要；通常组织成矩阵形式
     文本与标签组织：JSON 格式（Python 中对应字典结构）

第 04 章  数据预测建模：近邻分析  (P58-P69)
================================================================================

■ 核心思想："近朱者赤" —— 用邻居的输出值预测新样本

■ K-近邻法（KNN）基本流程
  为预测样本 X0 的输出 y0：
    ① 在训练集中找到与 X0 最相似的 K 个样本观测（X1,...,XK），称其近邻
    ② 对这 K 个近邻的输出值 (y1,...,yK) 计算算术平均（或加权均值/中位数/众数）
       作为 ŷ0
  特点：**不需要假定**输入输出关系的具体形式，只需指定 ŷ0 = f(y1,...,yK)

    回归预测：ŷ0 = (1/K) * Σ yi      （对 K 个近邻取均值）
    分类预测：ŷ0 = 取概率最大的类别 m（即众数类）

■ 两个核心问题
  问题一：用什么测度"近邻"？——距离定义
    闵可夫斯基距离：d(Xi, Xj) = [ Σ |Xik - Xjk|^m ]^(1/m)
    欧氏距离      ：d = √[ Σ (Xik - Xjk)² ]      （m=2）
    曼哈顿距离    ：d = Σ |Xik - Xjk|              （m=1）
    切比雪夫距离  ：d = Max( |Xik - Xjk| )
    夹角余弦距离  ：余弦相似度（注意与"距离"的区别）
    注意：必须消除数量级影响（标准化）

  问题二：K 取多少？——参数 K 的作用
    K 是 KNN 的关键参数，K 由小到大 → 模型复杂度由高到低、训练误差由小到大
    1-近邻法：
      · 适合类别边界极不规则的情形
      · 错判率不高于贝叶斯分类器错判率的 2 倍（重要理论界）
        贝叶斯错判率 = 1 - Pk*(X)
        1-近邻错判率 = 2 * Pk*(X) * (1 - Pk*(X)) ≤ 2 * (1 - Pk*(X))
      · 缺点：只依赖单个近邻，预测受近邻差异影响大，方差大、鲁棒性低
    K 增大：分类边界越来越规则平滑，不再"紧随数据点"
    偏差-方差特征：K 小 → 低偏差高方差；K 大 → 高偏差低方差

■ 加权 K-近邻法
  权重思想：相似性定义为距离的某种**非线性函数**；距离越近权重越高。
  权函数 K(d0i) 的三个要求：
    ① K(d0i) ≥ 0
    ② d0i = 0 时取最大值（零距离相似性最大）
    ③ K(d0i) 是 d0i 的单调减函数
  核函数：
    均匀核：K(d) = (1/2) * I(|d| ≤ 1)   → 等权重，等同于普通 KNN
    高斯核：K(d) = 1/(√(2π)) * exp(-d²/2) * I(|d| ≤ 1)
    d > 1 时两者相似性均为 0（即不再是近邻）
  加权预测：
    回归：ŷ0 = (1/K(w)) * Σ wi * yi
    分类：ŷ0 = arg max_C Σ wi * I(yi = C)
  优势：预测效果与 1-近邻持平，但能有效克服 1-近邻方差大、鲁棒性低的不足

■ KNN 的适用性  ★重要结论
  适用于：输入变量空间维度 p 较低、类别边界或回归线不规则的分类/回归问题
  不适用于高维：维度灾难
    空间维度 p 增加 → 基于"邻域"的局部性特征逐渐丧失 → 预测误差增大
    例证：E[d_p(r)] = r^(1/p)
          10 维空间中，r=0.01 时 E[d] = 0.63；r=0.1 时 E[d] = 0.8
          （即高维下"最近的邻居"其实也很远）
  结论：降低空间维度、选择重要输入变量对 KNN 非常重要（呼应第 9 章）

================================================================================
第 05 章  数据预测建模：决策树  (P70-P85)
================================================================================

■ 定位：机器学习核心算法之一，应用最广泛的分类/回归方法；
        也是第 6 章集成学习的基础学习器。

■ 什么是决策树
  得名于结果展示像一棵倒置的树。分为：
    分类树（分类预测） / 回归树（回归预测）
  树的结构术语：
    节点类型：根节点（最上）→ 中间节点 → 叶节点（最下）
    树深度  ：树根到树叶的最大层数，是**模型复杂度的度量**
    二叉树  ：每个父节点下仅有两个子节点（CART 属于二叉树），否则为多叉树
  本质：决策树是**数据反复分组**的图形化体现，每个节点对应一条推理规则；
        推理规则以逻辑判断形式反映输入输出的取值规律。

■ 决策树的预测
  对样本 X0，从根节点起依次按输入变量取值沿分枝"走到"某个叶节点（样本量 n）
    分类树：ŷ0 = arg max_k ( n_y1, n_y2, ..., n_yK )   → 叶节点中的众数类
            规则置信度 = n_yk / n （众数类占比）
    回归树：ŷ0 = (1/n) * Σ yi                          → 叶节点中输出变量的均值

■ 几何理解
  分类树的分类边界：叶节点各推理规则 ↔ 矩形区域一一对应
    树深度越大 → 矩形区域越多 → 边界连成极不规则的曲线
    → 可有效解决**非线性分类**问题
  回归树的回归平面：同理，树深度越大 → 平面越多 → 连成极不规则的回归曲面
  核心问题：如何确定 p 维空间划分的**先后顺序和位置**

■ 生长原则：异质性（Impurity）下降最大化
  每次分枝应使分出的两个区域内输出变量取值的异质性尽量低
    分类：低异质性 → 错判率低、推理规则置信度高
    回归：低异质性 → 离差平方和（MSE）最小
          min [ Σ(yi - ŷ_R1)² + Σ(yi - ŷ_R2)² ]

  异质性度量指标（CART）：
    分类树 —— 基尼（Gini）系数：G(t) = 1 - Σ P²(k|t) = Σ P(k|t)(1 - P(k|t))
              熵（Entropy）    ：Ent(t) = -Σ P(k|t) * log P(k|t)
              异质性下降：ΔG(t) = G(t) - [ (N_left/N_t)*G(t_left)
                                          + (N_right/N_t)*G(t_right) ]
              （熵的下降 ΔEnt(t) 形式完全相同）
    回归树 —— 方差：S²(t) = (1/N_t) * Σ (yi(t) - ȳ(t))²
              异质性下降：ΔS²(t) = S²(t) - [ (N_left/N_t)*S²(t_left)
                                            + (N_right/N_t)*S²(t_right) ]

■ 树的生长与剪枝  ★核心
  生长：不加限制则树不断生长，树深度↑ → 模型复杂度↑ → 训练误差↓
  极端情况：对 N 个样本做 N-1 次分枝得到 N 个叶节点 → 树深度最大、
            规则最复杂、边界最不规则 → **必然过拟合**

  预剪枝（Pre-pruning）：预设参数限制过度生长，三个参数
    ① 最大树深度  ② 最小样本量  ③ 最小异质性下降值

  后剪枝（Post-pruning）：从叶节点向根节点方向逐层剪掉分枝
    CART 采用**最小代价复杂度剪枝法（MCCP）**
      代价复杂度：R_α(T) = R(T) + α|T̃|
        其中 R(T) = 测试误差（各叶节点离差平方和之和），α|T̃| = 复杂度惩罚项
      核心矛盾：R(T) 小 → 复杂度高；复杂度低 → R(T) 大。二者不可同时小。
                因此只需 R(T) + α|T̃|（代价复杂度）较小即可。
      α 的作用：
        α = 0     → 不考虑复杂度，"最优树"= 叶节点最多的树（最茂盛）
        α 逐渐增大 → 复杂度影响增加
        α 足够大  → "最优树" = 只有根节点的树
      剪枝判据（对中间节点 t 及其子树 T_t）：
        若 R_α({t}) > R_α(T_t) → 保留子树
        若 α ≥ [ R({t}) - R(T_t) ] / ( |T̃_t| - 1 ) → 剪掉子树 T_t
        该比值越小且小于当前 α，说明子树对降低测试误差贡献越小，越应先剪

      MCCP 两阶段流程：
        第一阶段：从 α1=0 开始逐步增大 α，得到 K 个具有包含关系的
                  "当前最优树"序列 T_α1 ⊃ T_α2 ⊃ ... ⊃ T_αK（叶节点依次减少）
        第二阶段：在 K 个候选树中用**1-SE 规则**选出真正最优树
                  R(T_opt) ≤ min_k [ R_α(T_αk) + m × SE( R(T_αk) ) ]
                  m 为放大因子，SE 为测试误差的标准误

  CART（Classification And Regression Tree）：
    二叉树；采用**贪心算法**（不断寻找当前局部最优解）+ 自顶向下递归二分策略

================================================================================
第 06 章  数据预测建模：集成学习  (P86-P126)  ★篇幅最大、最重要
================================================================================

■ 动机：决策树有"天然"的高方差特征。集成学习是降低方差、
        提升预测性能的有效手段。

■ 6.1 集成学习的一般思路
  建模阶段：基于一组独立训练集，分别建立一组模型，每个称**基础学习器**
            （Base Learner）
  预测阶段：各基础学习器分别预测，再**平均**（回归）或**投票**（分类）
  两大作用：① 解决高方差问题 ② 将一组弱模型联合成强模型

■ 6.2 高方差的统计学解法
  若能基于同一总体的 B 个独立训练集，得到 B 个方差为 σ² 的独立回归预测值，
  则其平均值的方差降至 σ² / B。
      f̂_avg(x0) = (1/B) * Σ f̂^(b)(x0)
  现实问题：无法获得 B 个真正独立的训练集 → 用策略**模拟生成**
  主要策略：重抽样自举法（Bootstrap）

■ 6.3 重抽样自举法（Bootstrap）
  也称 **0.632 自举法**：
    对样本量为 N 的数据集 S 做**有放回**随机抽样 B 次，
    得到 B 个容量均为 N 的自举样本 S*_b（b=1,...,B）
  关键数字：N 较大时，某样本 N 次均未被抽中的概率
      (1 - 1/N)^N ≈ 1/e ≈ 0.368
    → 每个自举样本约包含 63.2% 的原始数据（"0.632"由此而来）
    → 未被抽中的约 36.8% 即该模型的 OOB（袋外观测）

■ 6.4 袋装法（Bagging = Bootstrap Aggregating）★
  适用：单个学习器**高方差、低偏差**时非常有效
  建模：基于 B 个自举样本训练 B 个基础学习器（通常是训练误差较低的
        相对复杂的模型，特指回归树/分类树）
  预测：
    回归：f̂_bag(x0) = (1/B) * Σ T*^(b)(x0)      （B 棵树预测值求均值）
    分类：统计 B 棵树中预测为第 k 类的占比，取占比最高的类
  测试误差估计（OOB 误差）：
    对每个样本观测 xi，只使用"xi 作为 OOB 时"的那些基础学习器的预测，
    取均值或投票 → 得到具有 OOB 特征的测试误差
    （优点：无需单独划分测试集，高效利用数据）
  输入变量重要性度量：
    某变量作为最佳分组变量时会使异质性下降，计算 B 棵树的
    **异质性下降总和**，总和最大 → 该变量最重要

■ 6.5 随机森林（Random Forests）★
  定义：用随机方式建立包含多棵决策树的"森林"，每棵树是一个基础学习器
  理论出发点：
    袋装法降方差的前提是 B 个预测值彼此独立 → 均值方差降至 σ²/B
    现实中独立难实现。若预测值两两相关系数为 ρ，则平均值的方差为：
        var(Z̄) = ρ*σ² + (1-ρ)/B * σ²
        当 B→∞ 时第二项趋于 0，只剩第一项 ρ*σ²
    → **降低树间相关性才能真正降方差**（这是随机森林超越 Bagging 的关键）
  多样性增强策略（三重随机扰动）：
    ① 对训练数据加随机扰动：重抽样自举
    ② 对输入变量加随机扰动：每个节点分裂时，从 p 个输入变量中
       随机选 m 个构成随机子集 Θb，只从 Θb 中选最佳分组变量
       通常 m = ⌊√p⌋ 或 m = ⌊log₂ p⌋
    ③ 对算法参数加随机扰动
  算法流程：
    for b = 1..B:
      重抽样自举 → S*_b
      基于 S*_b 建立树 T*^(b)（每次分裂只从随机 m 个变量中选最佳分组变量）
      直到满足预修剪参数为止
    输出：回归 → 均值；分类 → 得票最高的类
  评价：同样计算基于 OOB 的测试误差
  变量重要性（随机噪声法）：
    对第 j 个变量，随机打乱其 OOB 上的取值顺序，重新计算 OOB 误差
      c_j = e_j(T*^(b)) - e(T*^(b))     （打乱前后的误差变化）
    对 B 棵树求均值：变化值越大 → 第 j 个变量越重要
    （直观：重要变量被打乱后，模型性能应显著下降）

■ 6.6 从弱模型到强模型：提升法（Boosting）★
  弱模型定义：比随机猜测误差略低的模型
    二分类中随机猜测误差 = 0.5
    零模型（Zero Model）是典型弱模型；比零模型略好的才考虑输入变量
  联合预测（回归）：
      f̂_α(x0) = α1*f̂^(1)(x0) + α2*f̂^(2)(x0) + ... + αB*f̂^(B)(x0)
    αb 为模型权重。分类则为加权投票。
  与 Bagging 本质区别：这里的 B 个弱模型具有**顺序（sequential）相关性**

■ 6.7 AdaBoost（Adaptive Boosting）★
  经典形式用于 y ∈ {-1, +1} 的二分类
  算法框架（迭代式）：
    初始化：wi^(1) = 1/N（所有样本等权重）
    for b = 1..B:
      ① 基于权重 w^(b) 的训练集 Sb 建立弱模型 Gb(x)
      ② 计算训练误差：err_b = Σ wi^(b) * I(yi ≠ Gb(xi)) / Σ wi^(b)
      ③ 设置模型权重：α_b = log( (1 - err_b) / err_b )
      ④ 更新样本权重：wi^(b+1) = wi^(b) * exp( α_b * I(yi ≠ Gb(xi)) )
    最终预测：G(xi) = sign( Σ α_b * Gb(xi) )
  关键机制理解：
    · 预测正确的样本权重不变；预测错误的样本权重**增大**
      变为原来的 (1-err_b)/err_b 倍
    · 下一轮加权有放回抽样时，错误样本有更大概率进入训练集
      → 新模型专注学习前一个模型没学好的样本
    · 必须 err_b < 0.5（即 Gb 必须是弱模型），才能保证 α_b > 0
    · 大权重点基本集中在两类边界处（这是 AdaBoost 的几何特征）
  指数损失视角（深入理解）：
    采用指数损失函数 L(y, f) = exp(-y * f(x))
    可解得 β_b = (1/2) * log( (1 - err_b) / err_b )，且 α_b = 2*β_b
    样本权重可写为 wi^(b) = exp( -yi * f_(b-1)(xi) )，仅取决于 b-1 轮结果

  向前式分步可加建模（Forward Stagewise Additive Modeling）★
    每迭代一次，就有一个新弱模型加入"联合委员会"：
        f_b(x) = f_(b-1)(x) + α_b * G_b(x)
    特征：先前进入的模型参数和权重**不受后续模型影响**；
          每次迭代仅需估计当前模型。这是所有 Boosting 的统一框架。

  AdaBoost 回归版：
    损失函数（取值在 [0,1]）：
      线性损失：Li = |ŷi^(b) - yi| / D
      平方损失：Li = |ŷi^(b) - yi|² / D²
      指数损失：Li = 1 - exp( -|ŷi^(b) - yi| / D )
      其中 D = max( |ŷi^(b) - yi| )
    平均损失 L̄ = Σ Li * pi，pi 为归一化样本权重
    预测置信度（反向指标）：β_b = L̄ / (1 - L̄)，0 < β_b < 1
      L̄ 越小 → β_b 越小 → 置信度越高
    权重更新：wi^(b+1) = wi^(b) * β_b^exp(1 - Li)
    联合预测：取以 α_b 为权重的**加权中位数**（权重相等时即普通中位数）

■ 6.8 梯度提升树（GBDT）★
  定位：当下最流行的集成学习算法之一，梯度提升算法的典型代表
  三个要点：
    ① 采用向前式分步可加建模
    ② 迭代中用**梯度下降法**在函数集合中寻找使损失函数下降最快的模型
    ③ 提升 = 不断把新模型加入"联合委员会"，不断修正当前预测值
          f_b(x) = f_(b-1)(x) + β_b * h_b(x; a_b)
          h_b 本质是修正当前预测值的**增量函数**（incremental functions）

  优化过程（通用四步）：
    初始化 f_0(x) = 0
    for b = 1..B:
      ① 计算**伪响应变量**（pseudo-response）：
            ỹi = -g_b(xi) = -[ ∂L(yi, f(xi)) / ∂f(xi) ]|_{f = f_(b-1)}
      ② 求解模型参数（用最小二乘拟合伪响应）：
            a_b = arg min_{a,β} Σ ( ỹi - β*h(xi; a) )²
      ③ 线搜索学习率：
            ρ_b = arg min_ρ Σ L( yi, f_(b-1)(xi) + ρ*h_b(xi; a_b) )
      ④ 更新：
            f_b(x) = f_(b-1)(x) + ρ_b * h_b(x; a_b)
    直觉：β_b * h_b(xi; a_b) = -ρ_b * g_b(xi)，即沿负梯度方向修正

  梯度提升**回归**树（平方损失特例）：
    损失：L = (1/2) * (yi - f(xi))²
    → 伪响应变量 ỹi = yi - f_(b-1)(xi)，就是**当前残差**（非常重要的结论）
    基础学习器为含 J 个叶节点的回归树：
        h(x; b_j, R_j) = Σ b_j * I(x ∈ R_j)
        b_j = ave_{xi ∈ R_jb} ỹi       （区域内伪响应的均值）
        f_b(x) = f_(b-1)(x) + Σ γ_jb * I(x ∈ R_jb)
        γ_jb = arg min_γ Σ_{xi ∈ R_jb} L( yi, f_(b-1)(xi) + γ )
    因 J 个区域不相交，可对每个区域独立求解 γ

  GBDT vs AdaBoost 回归树（实验结论）：
    AdaBoost 约 25 次迭代后训练误差下降不明显
    GBDT 训练误差**持续降低**且未出现过拟合

■ 6.9 XGBoost 算法精要 ★
  三个特点：
    ① 每次迭代均针对**目标函数**（而非仅损失函数）进行
    ② 通过**二阶泰勒展开**得到损失函数的近似表达
    ③ 依据**结构分数（Structure Score）最小**求解决策树

  目标函数 = 损失函数 + 复杂度函数：
      obj^(b) = Σ L( yi, f_(b-1)(xi) + Σ_j γ_jb * I(xi ∈ R_jb) ) + Ω(f_b)
      XGBoost 定义的复杂度：Ω(ξ_b(x)) = ω*J + (1/2)*α*Σ γ_jb²
        J = 叶节点个数，γ_jb = 叶节点预测值（称**预测得分**）

  泰勒展开（二阶）：
      L ≈ L(yi, f_(b-1)(xi)) + gi * ξ_b(xi) + (1/2) * hi * ξ_b(xi)²
      其中 gi = ∂L/∂f|_{f_(b-1)}（一阶导），hi = ∂²L/∂f²|_{f_(b-1)}（二阶导）

  目标函数近似（关键推导结果）：
      obj^(b) ≈ Σ_j [ Gj * Θ_jb + (1/2) * (Hj + α) * Θ_jb² ] + ω*J
      其中 Gj = Σ_{xi∈j} gi，Hj = Σ_{xi∈j} hi，Θ_jb = γ_jb

  求解：对 Θ_jb 求导令为 0
      Θ_jb* = -Gj / (Hj + α)        （最优叶节点得分）
      代入得 obj^(b) ≈ -(1/2) * Σ_j [ Gj² / (Hj + α) ] + ω*J
      → 称为该树的**结构分数**，分数越低说明树结构越合理

  分裂增益（实际用于寻找最佳分组变量和组限值）：
      L_split = (1/2) * [ G_left²/(H_left+α) + G_right²/(H_right+α)
                          - Gj²/(Hj+α) ] - ω
      该值越大越好，应至少大于某个阈值（γ 最小分裂损失）
      直观：度量子节点相对父节点带来的目标函数减少程度

■ 6.10 各集成算法对比（实验结论）
    XGBoost ：收敛速度最快，约 20 次迭代即可达较低测试误差
    GBDT    ：测试误差最低，但需较多迭代（约 70 次）
    AdaBoost：约 25 次迭代后训练误差下降趋缓
    弱模型"联合委员会"：成员数 B 达 250 时测试误差已降至复杂模型水平，
                        之后甚至更低 → 印证"弱模型可联合成强模型"

第 07 章  数据预测建模：人工神经网络  (P127-P153)
================================================================================

■ 定位：人脑的抽象计算模型，模拟人脑思维的计算机建模方式
        用于解决模式识别、联想记忆、优化计算等复杂问题

■ 7.1 基本概念
  构成：由相互连接的**节点（处理单元）**组成
    节点间连线 = 连接（边）；连接权重的大小 = 生物神经元连接强弱
  拓扑结构分类：
    两层神经网络 / 三层及以上多层神经网络
    方向性连接的网络称为**前馈式网络**；各层节点全连接 → 全连接网络
  三类节点的功能：
    输入节点：一次接收一个样本观测，按"原样"传给下层
              个数 = 输入变量个数
    隐藏节点：对输入做计算，完成**非线性样本的线性变换**或特征提取
              层数和节点个数越多，模型越复杂
    输出节点：对上层输出加工后给出预测值
              个数取决于回归（1个）还是分类（K个）
  训练本质：探索输入输出间的数量关系，并将其**体现于连接权重**中
            神经网络训练的核心 = 连接权重的不断迭代更新

■ 7.2 感知机网络（两层：输入层 + 输出层）
  节点结构：加法器 + 激活函数

  加法器（加权求和 + 偏差）：
      V_k = Σ_p w_pk * X_p + θ_k = w_k^T * X + θ_k
      引入"虚拟"输入节点 X0 ≡ 1，令 w_0k = θ_k，可统一写为：
      V_k = Σ_{p=0..P} w_pk * X_p = w_k^T * X

  加法器的几何意义  ★
    分类：V_k = 0 表示 P 维输入变量空间中的一个**超平面** = 分类平面
          平面位置由连接权重 w_pk 和偏差权重 θ_k 决定
          每个输出节点 ↔ 一个超平面，将空间一分为二实现二分类
          V_ik(t) = 0 → 点落在平面上；>0 或 <0 → 落在平面两侧
          多分类需多个输出节点共同决定（如 (0,1)=1类，(1,0)=2类，(1,1)=3类）
    回归：V_k 表示一个**回归面**，V_k 即回归预测值 ŷ_k

  激活函数 f(V_k)：
    [0,1] 阶跃函数：  f(V) = 1 (V>0) ; 0 (V<0)
                      依据点与分类平面的位置关系直接给出类别
    (0,1) Logistic：  f(V) = 1 / (1 + e^(-V))
                      给出属于 1 类的**概率**，刻画非线性关系
    tanh 双曲正切：   f(V) = (e^V - e^(-V)) / (e^V + e^(-V))
    ReLU 整流线性单元：f(V) = max(V, 0)     ★实践中最常用
  偏差节点的意义：模拟生物神经元的**激活门槛（threshold）**
    只有 Σ w_pk * X_ip = -θ_k 时，点才落在平面上

  回归视角：投影寻踪回归（PPR）
    思想：将样本投影到待估计的新空间，使变换后易于找到数量关系
    模型：f(X) = Σ_k g_k( w_k^T * X )
    对应关系：w_k^T * X = 感知机的加法器 V_k；g_k(·) = 激活函数
    对单个输出节点 K=1

■ 7.3 感知机的权重训练
  损失函数：
    回归：L(y, ŷ) = (1/2) * (y - ŷ)²
          最优权重 (ŵ_k, θ̂_k) = arg min Σ (1/2)*( yi - f(w_k^T*xi + θ_k) )²
    分类：L(y, P̂(x)) = y*log P̂(x) + (1-y)*log(1 - P̂(x))   （交互熵）
          阶跃函数不适用时，改用基于**误分类点到超平面距离**的损失：
            距离 d_i = |θ_k + w_k^T*xi| / ||w_k|| = -yi*(θ_k + w_k^T*xi) / ||w_k||
            总损失 L(w_k, θ_k) = -Σ_{xi ∈ E} yi * (θ_k + w_k^T * xi)   （E=误分集）
            最优权重 = arg min [ 该总损失 ]

  迭代五步（t 时刻）：
    ① 初始化：w_k(0) 为随机数，θ_k(0)
    ② 输入样本 xi，计算输出：ŷ_ik(t) = f( Σ_p w_pk(t)*X_ip + θ_k(t) )
    ③ 计算 t 时刻 xi 的损失：E_i(t) = Σ_k L( y_ik, ŷ_ik(t) )
    ④ 沿负梯度更新权重：
         w_k(t+1) = w_k(t) - ρ * ∂E/∂w_k |_{w_k(t)}
         θ_k(t+1) = θ_k(t) - ρ * ∂E/∂θ_k |_{θ_k(t)}
       平方损失下：w_k(t+1) = w_k(t) + ρ * e_i(t) * xi
                  （或 (1/2)*ρ*e_i(t)*xi，取决于损失前的系数）
       分类（y∈{-1,+1}）下：w_k(t+1) = w_k(t) + ρ * yi * xi
    ⑤ 判断终止条件
  终止条件：
    · 迭代次数达到指定值
    · 训练周期（epoch）达到指定次数
    · 权重最大调整量小于指定值（权重基本稳定）
    · Σ E_i(t) < ε（ε 为很小的正数）

  权重更新的几何意义  ★
    迭代过程 = 超平面不断移动的过程，是超平面向错误点
    （错误分类或回归误差大的点）**移动靠近和跨越**的过程
    数学证明：Δd_i ≈ -ρ*yi²*( xi^T*xi + 1 ) / ||w_k(t)|| < 0
              → 一次迭代后误分类点更接近新的超平面
  局部最优问题：权重初始值随机 → 迭代结束值可能不等，有些是最优解
                有些仅是局部最优解 → 用**多次重启动**解决

■ 7.4 三种权重更新策略  ★重要
  在线更新（Online）：
    每次迭代只用当前 t 时刻输入的**单个样本**的损失
    样本输入顺序随机 → 梯度有随机性 → **随机梯度下降法（SGD）**
    所有样本都参与过一次更新 = 完成一个**训练周期（Epoch）**
    缺点：单个样本的负梯度方向不一定是总损失下降最快方向
  批量更新（Batch）：
    每次迭代基于**全体数据**的总损失
    优点：更新准确；缺点：计算代价很高
  小批量 SGD（Mini-Batch SGD）★实践首选：
    基于随机抽取的 n 个样本（1 < n < N）的损失更新参数
    n=1 是在线更新（真 SGD）的特例
    每个训练周期更新 N/n 次权重

■ 7.5 多层感知机与 B-P 反向传播算法
  多层网络结构：隐藏节点也由加法器 V 和激活函数 f 组成
    Z_m(t) = f( V_m(t) ) = f( Σ_p w_pm(t)*X_p(t) + θ_m(t) ) = f( w_m^T(t)*X(t) + θ_m(t) )
    一般形式：Z_m(t) = f( Σ_l w_lm(t)*O_l(t) + θ_m(t) ) = f( w_m^T(t)*O(t) + θ_m(t) )
    三层网络输出：
      回归（f = V）：ŷ_k = Σ_m v_mk * O_m(t) + θ_yk(t) = v_k^T(t)*O(t) + θ_yk(t)
      O(t) = Z(t) = ( f(w_1^T*X), f(w_2^T*X), ..., f(w_M^T*X) )^T
      多分类用 **Softmax**：ŷ_k = exp(V_yk(t)) / Σ_k exp(V_yk(t))

  隐藏节点的核心作用：实现**非线性样本的线性化变换**
    线性样本：存在超平面可将两类分开；否则为非线性样本

  B-P（Back-Propagation）反向传播算法  ★核心
    两阶段：
      正向传播：权重不变，逐层计算得到预测值，算出预测误差
      反向传播：将输出节点的预测误差**反方向逐层传播**到上层隐藏节点，
                逐层更新权重，直到所有层间权重全部更新
    局部梯度（Local Gradient）：
      输出节点：δ_ik = ( y_ik - ŷ_ik ) * f'( v_k^T * Z_i )
      隐藏节点：S_mi = f'( w_m^T * xi ) * Σ_k δ_ik * v_mk
        （隐藏节点的局部梯度受其相连的 K 个下层节点局部梯度影响，
          v_mk 视为影响权重，误差信息 y_ik - ŷ_ik 由此传递过来）
    权重更新（批处理策略）：
      v_mk(t+1) = v_mk(t) + ρ * Σ_i δ_mi * Z_im
      w_pm(t+1) = w_pm(t) + ρ * Σ_i S_mi * X_ip

■ 本章实践：手写体邮政编码识别
    建立不同隐藏节点数的三层感知机，激活函数依次为 ReLU 和 Logistic
    结论：采用 **ReLU 激活函数 + 5 个隐藏节点**的网络预测效果理想、
          泛化能力较强（节点过多会过拟合）

================================================================================
第 08 章  数据预测建模：支持向量机  (P154-P182)
================================================================================

■ 定位：1992 年由 Boser、Guyon 和 Vapnik 提出，建立在统计学习理论（SLT）
        基础上；在小样本、非线性、高维问题上有优势
  分为：支持向量分类机（SVC）+ 支持向量回归机（SVR）

■ 8.1 基本思路
  分类超平面：b + w1*X1 + ... + wp*Xp = 0，即 b + w^T*X = 0
  预测规则：b̂ + ŵ^T*X0 > 0 → ŷ0 = 1 ；< 0 → ŷ0 = -1
  核心问题：能分开两类的超平面可能有很多，选哪个？
  ★答案：选择具有**最大边界（Maximum Margin）**的超平面
          —— 距两类边缘观测点最远的超平面
  最大边界超平面的两大意义：
    ① 预测置信度高
    ② 仅取决于两类的**边缘观测点**（即支持向量）→ 鲁棒性强

■ 8.2 三种情形
    完全线性可分 / 广义线性可分（线性软间隔） / 线性不可分

■ 8.3 完全线性可分下的 SVC
  几何构造（二维直观）：
    ① 分别对两类最外围样本点连线，形成两个**凸包（Convex Hull）**
       （最小凸多边形，各类样本点均在多边形内或边上）
    ② 以一类凸包边界为基准线，过另一类凸包边界上的点作平行线
    ③ 找到能正确划分两类且**相距最远**的一对平行线
    ④ 最大边界超平面 = 该对平行线垂线的**垂直平分线**
  数学表述：
    基准线：b + w^T*X+ = 1  ；平行线：b + w^T*X- = -1
    两平行线间距：λ = 2 / ||w||  ；半间距（边界）d = 1 / ||w||
    正确分类约束：yi * ( b + w^T*xi ) ≥ 1    （i = 1..N）
    目标：max d  ⟺  min ||w||  ⟺  min τ(w) = (1/2)*||w||² = (1/2)*w^T*w
    → 典型的**凸二次型规划**问题，用拉格朗日乘子法求解

  拉格朗日求解（KKT 条件）：
    拉格朗日函数：L(w,b,a) = (1/2)*||w||² - Σ ai * ( yi*(b + w^T*xi) - 1 )
    对 w, b 求偏导令为 0：
        w = Σ ai * yi * xi      （超平面系数向量）
        Σ ai * yi = 0
    对偶问题：max L(a) = Σ ai - (1/2) * Σ_i Σ_j ai*aj*yi*yj*(xi^T*xj)

    KKT 条件：∇L = 0 ；g(x) ≤ 0 ；α ≥ 0 ；α*g(x) = 0（互补松弛）
    核心结论  ★：
      · ai = 0 的样本对超平面**不起作用**
      · ai > 0 的点 = **支持向量**，决定最大边界超平面
      · KKT 条件知：支持向量落在两类的边界线上
    偏置计算：b = yi - w^T*xi（任选一个支持向量；多选几个取均值更稳定）
    预测：h(x0) = Sign[ b + Σ_{i=1..L} ai * yi * (xi^T * x0) ]

■ 8.4 广义线性可分（软间隔）★实践中最常用
  问题：完全线性可分约束太严格 → 允许部分点进入"禁区"
  松弛变量 ξi ≥ 0：度量样本点与类边界、超平面的位置关系
    约束条件变为：yi * ( b + w^T*xi ) ≥ 1 - ξi
    ξi = ei * ||w|| = ei / d（相对度量）
  错误惩罚参数 C  ★
    目标函数：min (1/2)*||w||² + C * Σ ξi
    C 的作用：平衡"边界宽度"与"训练误差"，即平衡**模型复杂度与误差**
      C → 0  ：最小化第一项 → 边界最宽 → 模型最简单（等价随机猜测）
      C → ∞  ：主要取决于最小化 Σξi → 边界最窄 → 模型复杂度最高（易过拟合）
      C 大 → 对误差容忍度低 → 边界窄
      C 小 → 对误差容忍度高 → 边界宽
    调参方法：一般通过 **K 折交叉验证**确定
  软间隔下的支持向量：落在两类边界线上（ξi = 0）**和**"禁区"内（ξi > 0，ai = C）
    因为 ai = C - μi，ξi > 0 时 μi = 0，故 ai = C

■ 8.5 线性不可分：核函数技巧 ★★本书最精妙的部分
  一般思路：低维线性不可分 → 非线性映射到高维 → 高维线性可分
    映射：X → φ_M(X) ∈ R^M；再在 R^M 中找最大边界超平面
    注意：R^M 中的超平面，在原空间中看起来可能是**曲面（曲线）**
  维灾难：高维下待估参数太多，组合数 = (p+d-1)! / ( d! * (p-1)! )
  ★SVM 的破解之道：从**点积**入手
    观察：对偶目标函数中，决定超平面参数的只是点积 xi^T*xj
          预测时也只取决于 x0 与 L 个支持向量的点积
    核函数定义：K(xi, xj) ≡ φ_M(xi)^T * φ_M(xj)
      → 一旦确定核函数，就**不必显式做空间变换**，也不用关心 φ 的具体形式
      → 只需计算核函数即可，实现低维到高维的"隐式"变换
    经典例子（多项式核的等价性）：
      p=2，φ_3(X1,X2) = (X1², X2², Z)^T，Z = 2*X1*X2
      φ_3(xi)^T * φ_3(xj) = (X_i1*X_j1 + X_i2*X_j2)² = (xi^T*xj)² = K(xi,xj)
      → 直接在二维空间算 K 即可，无需真的升到三维

  常用核函数：
    线性核    ：K(xi,xj) = xi^T*xj = Σ_p X_ip*X_jp（即原空间点积）
    d 阶多项式核：K(xi,xj) = ( 1 + γ * xi^T*xj )^d
    径向基核（RBF）★最常用：
                K(xi,xj) = exp( -||xi - xj||² / (2σ²) ) = exp( -γ*||xi-xj||² )
                γ = 1/(2σ²)
    Sigmoid 核：K(xi,xj) = 1 / ( 1 + exp( -γ*||xi-xj||² ) )

■ 8.6 支持向量回归（SVR）
  核心思想：用一条**"宽带"**代替传统的回归"细线"去贯穿和拟合样本观测点
            （除非数据轮廓变化大或对误差要求严格，"宽带"才会上下弯曲）
  ε-带与"管道"：
    ε-不敏感损失函数（ε-insensitive error function）：
        V_ε(ei) = 0,           |ei| < ε
                  |ei| - ε,    |ei| ≥ ε
    （残差绝对值不超过 ε 时不计入损失 → 实现对微小变动的"免疫"）
    多变量下 ε-带演变为直径 > 0 的"管道"，管内残差视为 0
  参数 ε 的作用：
    ε 过大 → 管道过宽，极端情况所有 V_ε = 0 → 回归线平行于 x 轴、
              位于 y 均值处（最简单、扁平化程度最大）
    ε 过小 → 管道过窄 → 回归曲面"紧随"样本点（易过拟合）
    ε 不能过大也不能过小，通过 K 折交叉验证确定
  目标函数：
    min (1/2)*||w||² + C * Σ ( ξi + ξi* )
    第一项小 → 管道宽 → 鲁棒性强，但 Σ(ξi+ξi*) 会大
    第二项小 → 误差低，但需管道窄（可能过拟合）
    → 两项不可同时小，求二者之和最小 → 管道宽度合理且位置角度恰当
    C 大 → 倾向跟随管道外部的点（复杂模型）
    C 小 → 倾向扁平化（简单模型）
  约束与解：
    约束：b + w^T*xi - yi ≤ ε + ξi ； yi - b - w^T*xi ≤ ε + ξi*
    回归系数解：w = Σ_i ( ai* - ai ) * xi
    预测：f(x0) = Σ_{i=1..L} ( ai* - ai ) * K(xi, x0) + b
    支持向量落在"管道"的边缘和外部

================================================================================
第 09 章  特征选择：过滤、包裹和嵌入策略  (P183-P197)
================================================================================

■ 为什么需要特征工程（问题驱动）
  变量过多可能导致的问题：
    ① 带来更多数据噪声 → 模型过拟合
    ② 输入变量间相关性 → 对某因素影响效应的估计出现大的偏差和波动
    ③ 增加计算的时间复杂度和存储复杂度
    ④ 变量数 > 样本量时**无法求解**模型参数
    ⑤ 高维下样本稀疏性远高于低维，不利于建模（维灾难）
  两个概念：
    特征选择：从众多输入变量中**筛选出**有意义的重要变量，减少变量个数
    特征提取：从众多**相关**变量中提取出较少的**综合变量**替代原有变量
    （二者都实现降维，但思路不同）

■ 特征选择的三种策略
  过滤式（Filter）  ：特征选择与预测建模"**分而治之**"，先筛再建模
  包裹式（Wrapper） ：把特征选择"包裹"进一个指定预测模型中，
                      以该模型作为评价变量重要性的工具
  嵌入式（Embedding）：特征选择"嵌入"整个预测建模过程，与建模"融为一体"

■ 9.1 过滤式策略
  (1) 低方差过滤法（Low Variance Filter）
      变量取值差异很小 → 不会对预测模型产生影响
        数值型：计算方差
        分类型：计算 Nk/N（各类样本量占比）或 K/N（类别数与样本量之比）
  (2) 高相关过滤法（High Correlation Filter）
      ① 数值型 X vs 分类型 y → 方差分析（ANOVA），F 统计量
         原假设 H0：μ1 = μ2 = ... = μk ；备择假设 H1：各 μ 不全相等
         SST = Σ_k Σ_i (X_ki - X̄)²      （总离差平方和）
         SSA = Σ_k Nk*(X̄_k - X̄)²        （组间，因素A导致）
         SSE = Σ_k Σ_i (X_ki - X̄_k)²    （组内，随机因素导致）
         F = [ SSA/(K-1) ] / [ SSE/(N-K) ] = MSA / MSE
         基于小概率原理的反证法；显著性水平 α = 弃真错误概率；计算 P 值
      ② 分类型 X vs 分类型 y → 卡方检验，χ² 统计量
         原假设 H0：y 与 X 不相关 ；备择 H1：相关
         χ²_观测 = Σ_i Σ_j ( F_ij - N_ij )² / F_ij
         （F_ij 为实际频数，N_ij 为期望频数）

■ 9.2 包裹式策略
  基本思路：反复迭代，每次剔除当前最不重要的变量，得到嵌套子集
      S1 ⊂ S2 ⊂ ... ⊂ Sp
  递归式特征剔除（RFE）★（以支持向量机为例）
    当前变量集 S = {X1,...,Xp}，重要变量集 r0 = 全集
    for 每次迭代：
      ① 基于 S 训练 SVM 模型 M_S
      ② 计算变量重要性：wi(M_S) = Σ_{n=1..L} a_n * y_n * X_ni
                        以 [ wi(M_S) ]² 作为重要性度量
      ③ 找到 min( [wi]² ) 对应的变量，从 S 中剔除，记录 rp ← S
    → 得到若干重要变量子集 r0 ⊃ r1 ⊃ ... ⊃ rp（变量个数依次减少）
  特点：评价准确但计算代价高（需反复训练模型）

■ 9.3 嵌入式策略：正则化  ★核心
  思想：若变量重要 → Σβ² 或 Σ|β| 应很大；反之应很小
        → 指定 Σβ² ≤ s 或 Σ|β| ≤ s 作为约束，迫使不重要变量系数趋于 0
  范数定义：
    L2 范数平方：||β||₂² = Σ βi²
    L1 范数    ：||β||₁  = Σ |βi|
  目标函数（等价的正则化形式）：
    岭回归（Ridge，L2 正则化）：
        obj(β) = Σ_i ( yi - β0 - Σ_j βj*X_ij )² + α * Σ_j βj²
    Lasso 回归（L1 正则化）：
        obj(β) = Σ_i ( yi - β0 - Σ_j βj*X_ij )² + α * Σ_j |βj|
    第二项 = **正则化（Regularization）项**，本质度量模型复杂度
  L1 vs L2 的几何直观  ★★为什么 Lasso 能做特征选择
    约束区域形状：L2 是**圆（球）**，L1 是**菱形（多面体）**
    最优解在等高线与约束区域的**切点**处
    L1 的菱形有**尖角（顶点）**，落在坐标轴上的概率更高
    → L1 有更高概率使某些 βi **严格等于 0**
    → 从特征选择角度应倾向采用 **L1 正则化**；βi = 0 的变量即不重要变量
  收缩参数 α 的作用：
    α → 0  ：几乎不惩罚 → 模型复杂度最高（可能过拟合）
    α → ∞  ：强惩罚 → 所有 βi = 0 → 最简单的模型
    α 起到**平衡训练误差与模型复杂度**的作用

■ 9.4 弹性网回归（Elastic Net）
  动机：Lasso 更适合作特征选择；但岭回归最优解下的损失函数更小
        → 结合两者，同时引入 L1 和 L2 正则化
  目标函数：
    Σ_i ( yi - β0 - Σ_j βj*X_ij )² + α * Σ_j ( γ*βj² + (1-γ)*|βj| )
    γ ∈ [0,1]：γ=0 时为 Lasso，γ=1 时为岭回归，称 γ 为 **L2 范数率**
  （Python/sklearn 中的参数化略有不同：γ=0 为岭回归，γ=1 为 Lasso，
    称 γ 为 L1 范数率，使用时注意区分）

第 10 章  特征提取：空间变换策略  (P198-P219)
================================================================================

■ 10.1 主成分分析（PCA）
  基本出发点：通过坐标变换，把样本点从 X1..Xp 空间"放置"到 y1..yp 空间，
              使数据点在较多的 yi 上近似 **0 方差** → 依低方差过滤思想略去
  数学表述（Xi 已标准化：E(Xi)=0, var(Xi)=1）：
      y1 = μ11*X1 + μ12*X2 + ... + μ1p*Xp
      y2 = μ21*X1 + μ22*X2 + ... + μ2p*Xp
      ...
      yp = μp1*X1 + μp2*X2 + ... + μpp*Xp
    约束：各系数平方和为 1（μi1² + μi2² + ... + μip² = 1）
          y1,...,yp **两两不相关**
    矩阵形式：y = X * U （U 为 p×p 正交系数矩阵）
  主成分的定义（依次最大化方差）：
    y1：X1..Xp 一切线性组合中方差**最大**者
    y2：与 y1 不相关的一切线性组合中方差**次大**者
    ...
    yp：与前 p-1 个都不相关者中方差**最小**者
    → 方差依次递减，包含的"信息"依次递减
  求解（拉格朗日 + 特征分解）★
    优化问题：max var(y) = U^T * R * U   s.t.  U^T * U = I
              （R 为相关系数矩阵）
    拉格朗日函数：L = U^T*R*U - λ*( U^T*U - I )
    求导令为 0：R*U = λ*U
    → **求相关系数矩阵 R 的特征值 λ1 ≥ λ2 ≥ ... ≥ λp > 0
       及对应的单位特征向量 u1,...,up**，再计算 yi = X * ui
    主成分方差：var(yi) = ui^T * R * ui = ui^T * λi * ui = λi
  确定保留几个主成分：
    ① 特征值准则（Kaiser）：选取 λi > 1 的主成分
    ② 累计方差贡献率：CR_k = ( Σ_{i=1..k} λi ) / ( Σ_{i=1..p} λi )
                     通常选择 CR_k > 0.80 时的 k

■ 10.2 矩阵的奇异值分解（SVD）
  基本思路（从 PCA 推广）：
    PCA：Y(N×2) = X(N×2) * U(2×2)
    标准化：Z(N×2) = Y(N×2) * D(2×2)^(-1)，其中 D^(-1) = diag(1/λ1, 1/λ2)
    即 Z = X * U * D^(-1)
      U 为正交矩阵 → 实现**正交旋转**
      D^(-1) 为对角阵 → 实现**"伸缩"**处理（把长椭圆拉成圆）
    反解：X = Z * D * U^T （因 U*U^T = U^T*U = I）
  一般形式：任意 M×N 数据矩阵 X 可分解为
      X = U * D * V^T
      U(M×M)：每列由 X*X^T 的特征向量组成
      D(M×N)：对角矩阵，对角元素为 X*X^T 从大到小的 M 个特征值
      V(N×N)：每行由 X^T*X 的特征向量组成
  应用：若只选前若干个较大特征值对应的特征向量 → X ≈ U*D*V^T
        → 实现数据压缩与降维（如图像压缩、推荐系统）

■ 10.3 核主成分分析（KPCA）
  定位：PCA 的**非线性**拓展
  思路：
    ① 用非线性映射 φ 把输入空间 R^p 中的点 xi 映射到极高维特征空间
       F = (F1,...,FM)，即 Fi = φ(xi) ∈ R^M
    ② 在特征空间中做 PCA，并用**核函数**解决维灾难
  数学表述：y = F * B（B 为 M×M 正交矩阵，B^T*B = I）
    目标：max var(y) = B^T * Σ(F) * B   s.t. B^T*B = I
    求导得：Σ(F) * B = λ_F * B
  核技巧（与 SVM 同构）★
    难点：无法直接计算 Ψ(xi) 与 Ψ(xj) 的点积
    解决：找核函数 K(xi,xj) ≡ Ψ(xi)^T * Ψ(xj)
          → 无需关心 φ 的具体形式就能确定协方差矩阵
          → 记 Σ(F̃) = K，称为**核矩阵**
          → 只需计算 K 的特征值和特征向量：K * B̃ = λ_F̃ * B̃
    其中 Ψ(xi) = φ(xi) - (1/N)*Σ_j φ(xj)（中心化）

■ 10.4 因子分析（Factor Analysis）
  定位：通过空间变换实施特征提取的经典**统计**方法
  出发点：众多变量之所以相关，是因为受某种**潜在的共性因素**影响
    例：六门课程成绩相关系数矩阵中，任两列各行元素大致成比例
        （如 0.83/0.67 ≈ 0.70/0.64 ≈ 0.66/0.54 ≈ 0.63/0.51 ≈ 1.2）
        → 说明存在共同的潜在因素（如班级整体学习能力/智力水平）
    推导：Xi = a_i*f + εi，E(Xi)=0, var(Xi)=1, E(f)=0, var(f)=1
          Cov(Xi, Xj) = E[(ai*f + εi)(aj*f + εj)] = ai*aj*var(f) = ai*aj
          Cov(Xi,Xj) / Cov(Xk,Xj) = ai / ak   → 成比例的原因
  数学模型：X = A*F + ε
    X = (X1,...,Xp)^T       原有变量
    F = (f1,...,fk)^T       **公共因子**（潜在因素的测度，不可见）
    A = (a1,...,ap)^T       因子载荷矩阵，aij 为 Xi 在 fj 上的**载荷**
    ε                      **特殊因子**（未被因子全体解释的部分）
                            E(εi)=0, cov(εi,f)=0, cov(εi,εj)=0
  因子载荷的含义 ★
    aij = corr(Xi, fj) = cov(Xi, fj)  → Xi 与 fj 的相关系数
      绝对值越接近 1 → 相关性越强
    aij² 反映因子 fj 对变量 Xi **方差的解释程度**，取值 0~1
    var(Xi) = Σ_j aij² + var(εi) = Σ_j aij² + εi² = 1
    → 特殊因子方差 εi² = 1 - Σ_j aij²，称**剩余方差**
    → εi² 越小，因子对 Xi 的解释越充分，信息丢失越少（这是所希望的）

  因子分析的评价（信息丢失度量）：
    ① 变量共同度 hi² = Σ_j aij²（对单个变量 Xi 的信息保留程度）
       大多数变量的 hi² 高于 0.8 → 因子分析较为理想
    ② 因子 fj 的方差贡献：Sj² = Σ_i aij²
       方差贡献率：Rj = Sj² / p
       累计方差贡献率通常应 > 80%

  因子载荷矩阵的求解（主成分法）：
    从主成分出发：yi = μi1*X1 + ... + μip*Xp
    反解：Xi = μ1i*y1 + μ2i*y2 + ... + μpi*yp
    标准化使因子方差为 1：fj = yj / λj
    令 aij = μji / λj ，得到 A = [ μji / λj ]
    → 因子个数 k < p，故因子载荷矩阵只取**前 k 列**
    → k 由特征值 λi 或累计方差贡献率确定

  因子得分的计算：
    希望计算样本 xi 在 fj 上的得分：f_ij = b_j1*X_i1 + ... + b_jp*X_ip
    线性组合近似：F = X * w
    两边乘 (1/N)*Σ X^T 得：A = R * w（R 为相关系数矩阵，A 为因子载荷阵）
    → w = R^(-1) * A
    → **F = X * R^(-1) * A**

第 11 章  揭示数据内在结构：聚类分析  (P220-P236)
================================================================================

■ 11.1 一般问题
  聚类的目的：基于 p 个聚类变量，发现数据中可能存在的"自然小类"，
              通过小类刻画和揭示数据的**内在组织结构**
  （对比：主观分组 vs 客观发现。典型场景：基于 RFM 的市场细分
    R=最近一次消费 Recency，F=消费频率 Frequency，M=消费金额 Monetary）

  "类"的三种定义视角：
    ① 聚类变量空间中**距离较近**的各样本观测点
    ② 聚类变量空间中样本点**分布较密集**的区域
    ③ 来自某**特定统计分布**的一组样本观测
  聚类方法分类：
    按结果：确定性聚类 / 模糊聚类；层次聚类 / 非层次聚类
    按模型：
      基于质心的聚类模型（Centroid Models）        → K-均值
      基于联通性的聚类模型（Connectivity Models）  → 系统聚类
      基于统计分布的聚类模型（Distribution Models）→ EM 聚类
      基于密度的聚类模型（Density Models）         → DBSCAN（第12章）

  聚类解的评价  ★（聚类没有标准答案，评价很关键）
    基本原则：小类内部差异小、小类之间差异大
    核心问题：判断聚类数目 K 是否合理
    ① 内部度量法（无需真实标签）
       类内/类间离差平方和：
           F = [ SSX_between / (K-1) ] / [ SSX_within / (N-K) ]
           F 越大 → K 越合理
       CH（Calinski-Harabaz）指数：CH = D(between)² / D(within)²
           CH 越大 → K 越合理
       轮廓系数（Silhouette）：
           a(x0) = x0 在所属小类 k 的总代价
           b(x0) = x0 在其他小类的总代价的最小值
           总代价 = Σ_i Σ_j ( X_ij^(k) - X_0j )²
           s(x0) = [ b(x0) - a(x0) ] / max( a(x0), b(x0) )
           s → 1  ：聚类合理
           s → -1 ：很可能被归入错误的小类
    ② 外部度量法（需真实标签作参照）
  聚类解可视化：高维降维到二维散点图展示

■ 11.2 K-均值聚类（基于质心）
  特点：
    以小类的**质心**为核心，视距质心较近的样本为一类
    聚类解是**确定性**的、**不具有**层次关系
    **需事先指定**聚类数目 K
  五步流程：
    ① 指定聚类数目 K
    ② 确定 K 个小类的初始质心
    ③ 根据"最近原则"进行聚类（把每个点分到最近质心所在的类）
    ④ 重新计算 K 个类的质心
    ⑤ 判断是否满足终止条件（不满足则回到③）

■ 11.3 系统聚类 / 层次聚类（基于联通性）
  特点：
    从距离和联通性角度设计算法；结果为确定性且**具有层次关系**
    通常是将各样本点逐步合并成小类，再逐步合并成中类、大类
  步骤：
    ① 每个样本观测点自成一类（共 N 类）
    ② 计算所有点彼此距离，把最近的两个点聚成一个小类 → 得到 N-1 类
    ③ 度量剩余点与小类间的距离，把当前距离最近的点或小类再聚成一类
    ④ 重复，直到所有点"凝聚"成一个最大的类
    → 对 N 个样本需经 N-1 次"凝聚"
  联通性（类间距离）的四种定义：
    最近邻法（single linkage）
    最远距离法（maximum linkage）
    组间平均链锁法（average linkage）
    类内方差 Ward 法
  优势：可一次性给出 K=1,2,...,N 时的**所有**聚类解
        → 为确定合理的 K 提供直接依据（这是相对 K-均值的重要优点）

■ 11.4 EM 聚类（基于高斯分布）★
  出发点：有限混合分布
    若数据存在"自然小类"，则某小类中的样本一定来自一个**高斯分布**
    一个自然小类 = 来自一个高斯分布的随机样本
    数据集全体 = 来自多个高斯分布的**有限混合分布**的随机样本
      f(X1,...,Xp | θ) = Σ_k λk * fk(X1,...,Xp | θk)
  难点：成分参数 θ 未知，**各样本所属小类标签 Ci 也未知**
        → 样本信息不完整 → 无法直接用极大似然估计
  EM 算法（Expectation-Maximization，期望-最大值法）：
    在**潜变量**（小类 C）和分布参数 θ 均未知时，通过多次迭代最大化似然函数
  算法流程：
    初始化：从参数空间中随机指定 θ(0) = { μk(0), Σk(0) }, k=1..K
            （相当于 K-均值中的初始类中心）
    E 步（Expectation）：在 θ(t) 下计算各样本属于各小类的概率
        f( xi | μk, Σk ) = 1/( (2π)^(p/2) * |Σk|^(1/2) )
                           * exp( -(1/2)*(xi-μk)^T * Σk^(-1) * (xi-μk) )
        P( Ci(t)=k | xi ) = f( xi | μk(t), Σk(t) ) / Σ_j f( xi | μj(t), Σj(t) )
        将 xi 指派到概率最大的小类
    M 步（Maximization）：在 C(t) 下更新成分参数
        μk(t+1) = Σ_i [ P(Ci(t)=k | xi) * xi ] / Σ_i P(Ci(t)=k | xi)
        Σk(t+1) = Σ_i [ P(Ci(t)=k | xi) * xi * xi^T ] / Σ_i P(Ci(t)=k | xi)
    重复 E 步与 M 步，直到小类标签 C 和参数 θ 均收敛

第 12 章  揭示数据内在结构：特色聚类  (P237-P251)
================================================================================

■ 12.1 DBSCAN 聚类（基于密度）★
  全称：Density Based Spatial Clustering of Applications with Noise
  两大突出特色：
    ① 利用小类的**密度可达性**，可发现**任意形状**的小类（K-均值做不到）
    ② 聚类同时可发现数据中的**噪声点（离群点）**
  两个关键参数：
    邻域半径 ε
    邻域半径 ε 内包含的最少观测点个数 minPts
  四类点的定义：
    核心点 P：样本点 O 的 ε 邻域内邻居个数 ≥ minPts
    直接密度可达点 Q：点 Q 在核心点 P 的 ε 邻域范围内
    密度可达点 Q：存在点列 O1,...,On，O(i+1) 是 Oi 的直接密度可达点，
                  O1=P, On=Q → 从 P 密度可达 Q
    噪声点：不属于任何小类的点
  聚类过程两阶段：
    第一阶段（形成小类）：
      从任一点 Oi 开始，判断是否为核心点
        是 → 标记为核心点，找到其所有直接密度可达点，形成以它为核心的小类 Ci
        否 → 可能是其他核心点的（直接）密度可达点（后续会被归入某类 Cj），
             也可能是噪声点（始终不带类标签）
    第二阶段（合并小类）：
      判断各核心点之间是否存在密度可达/密度相连关系，若存在则合并相应小类
  注意：DBSCAN 对参数（ε, minPts）**敏感**，需谨慎调参

■ 12.2 Mean-Shift 聚类（基于密度，2002年提出）
  基础：核密度估计（KDE）
    直方桶思路：第 k 个桶中心 cs_k 的概率密度 f(cs_k) = (Nk/N) / h
                Nk = 落入该桶的样本量，N = 总样本量
    均匀核：K( ||cs_k - Xi|| ) = 1 (|d| ≤ h/2) ; 0 (|d| > h/2)
    核密度估计：f̂_{h,K}(cs_k) = (1/(h*N)) * Σ K( ||cs_k - Xi|| )
                             = (1/N) * Σ K( ||(cs_k - Xi)/h|| )
    高斯核：K(||cs_k - Xi||) = 1/(√(2π)*h) * exp( -||cs_k - Xi||² / (2h²) )
    p 维空间：f̂ = (c_k / (N*h^p)) * Σ K( ||(cs_k - Xi)/h||² )
  核心思想：
    通过 **∇f̂(cs_k) = 0** 找到高密度区域的中心点，即小类的中心
  均值漂移向量（Mean Shift Vector）：
    令 g(X) = -K'(X)，G(X) = c_g * g(||X||²)
    m_{h,G}(cs_k) = [ Σ Xi * g(||(cs_k-Xi)/h||²) / Σ g(||(cs_k-Xi)/h||²) ] - cs_k
    梯度关系：∇f̂_{h,K}(cs_k) = f̂_{h,G}(cs_k) * (2*c_k/(c_g*h²)) * m_{h,G}(cs_k)
    → m_{h,G} 正比于核密度梯度，沿它移动即沿密度上升最快的方向移动
  聚类过程：
    ① 令样本点 Xi 作为小类初始中心 cs_k(0) = Xi，迭代：
       计算 m_{h,G}(cs_k)
       若 m_{h,G}(cs_k) > ε（阈值），则把类中心移到
           cs_k(t+1) = Σ Xi*g(||(cs_k(t)-Xi)/h||²) / Σ g(||(cs_k(t)-Xi)/h||²)
    ② 判断最终中心 T 是否与已有小类中心重合；不重合 → 得到新的小类中心
  特点：**无需事先指定**聚类数目 K，但 K 与核宽 h 有关
        → 通常核宽 h 越小，聚类数目 K 越大

■ 12.3 BIRCH 聚类
  全称：Balanced Iterative Reducing and Clustering using Hierarchies
  两大特色：
    ① 有效解决计算资源（尤其是**内存**）有限条件下的高维大数据集聚类
    ② 能够实现**在线数据的动态聚类**
  核心数据结构：聚类特征树（CF Tree）
    聚类特征 CF_k = ( N_k, Σ Xi1, Σ Xi2, ..., Σ Xip,
                            Σ Xi1², Σ Xi2², ..., Σ Xip² )
      （即：样本数、各维线性求和、各维平方求和）
  引入聚类特征的两大好处：
    ① 只需 CF 就能算出小类质心、类内离散程度等信息
    ② 只需 CF 就能算出点与小类间的距离（或类内离差平方），
       快速完成小类的指派 → **无需存储原始数据**，极大节省内存
  决定 CF 树规模的两个参数：
    分枝因子 B：每个非叶节点包含的子类个数 ≤ B
    阈值 T    ：叶节点允许的最大"半径"（叶节点中样本点两两距离的平均值），
                是判断点 Xi 能否并入该叶节点的依据
    B 与 T 具有内在联系
  BIRCH 核心步骤：
    ① 初始化 CF 树：随机抽取若干（< B）个样本点作为各子类初始中心
    ② 对每个样本点 Xi：
        第一步：沿"最近路径"找到距 Xi 最近的叶节点 Cmin
        第二步：判断 Xi 并入 Cmin 后，叶节点半径 d 是否仍 < 阈值 T
        第三步：重新计算每个节点的 CF，为处理下一个点做准备
  注意：CF 树各节点**不直接存储数据本身**，只存储聚类特征

附录 A  关键概念速查表
================================================================================

【误差与评价】
  训练误差    ：基于训练集（袋内观测）的误差，是泛化误差的偏低估计
  测试误差    ：基于测试集（OOB 袋外观测）的误差，作为泛化误差的估计
  泛化误差    ：模型在新数据上的误差，理论上无法直接计算
  偏差 Bias   ：预测值期望与实际值之差（准不准）
  方差 Var    ：多个预测值自身的波动程度（稳不稳）
  OOB         ：Out-Of-Bag，未被抽入自举样本的样本观测（约 36.8%）
  MSE         ：均方误差，回归任务的主要指标
  ROC/AUC     ：二分类的图形化评价工具
  宏平均/微平均：多分类评价指标的两种聚合方式

【数据集划分】
  旁置法 Hold out    ：随机划分为训练/测试两部分
  留一法 LOO         ：N-1 训练、1 测试，重复 N 次
  K 折交叉验证 CV    ：随机等分 K 份，轮流取 1 份测试（最常用）

【损失函数】
  平方损失   ：回归，L = (y-ŷ)²
  交互熵     ：分类，L = -log P̂y(x)
  指数损失   ：AdaBoost，L = exp(-y·f(x))
  二项偏差   ：L = -y·f̂(x) + log(1+exp(f̂(x)))
  ε-不敏感损失：SVR，|e| < ε 时不计损失

【距离度量】（第4章 KNN）
  闵可夫斯基 / 欧氏 / 曼哈顿 / 切比雪夫 / 夹角余弦

【核函数】（第4章加权KNN、第8章SVM、第10章KPCA、第12章Mean-Shift 通用）
  线性核 / d阶多项式核 / 径向基核 RBF / Sigmoid 核 / 均匀核 / 高斯核

【树模型异质性指标】
  Gini 系数、熵（分类树）；方差（回归树）

【集成学习】
  Bagging     ：并行，Bootstrap 重抽样，降方差
  随机森林    ：Bagging + 变量随机子集，进一步降相关性
  AdaBoost    ：串行，样本权重自适应调整，指数损失
  GBDT        ：串行，梯度下降 + 伪响应变量（残差）
  XGBoost     ：GBDT + 二阶泰勒展开 + 结构分数 + 正则化
  基础学习器  ：集成中的单个模型
  向前式分步可加建模：Boosting 的统一框架

【神经网络】
  加法器 / 激活函数（阶跃、Logistic、tanh、ReLU）/ 局部梯度 / B-P 反向传播
  SGD / 批量 / 小批量（Mini-Batch）三种更新策略
  Epoch：所有样本均参与过一次权重更新

【特征工程】
  特征选择：过滤式 / 包裹式（RFE）/ 嵌入式（Ridge、Lasso、Elastic Net）
  特征提取：PCA / SVD / KPCA / 因子分析
  L1 正则化 → 产生稀疏解 → 可做特征选择
  L2 正则化 → 系数收缩但不为 0 → 降方差

【聚类】
  基于质心：K-均值
  基于联通性：系统聚类（single/maximum/average linkage, Ward）
  基于分布：EM 聚类（有限混合分布 + E步/M步）
  基于密度：DBSCAN、Mean-Shift
  大数据在线：BIRCH（CF 树）
  评价指标：F 比、CH 指数、轮廓系数 Silhouette

附录 B  重要结论汇总（核心必记）
================================================================================

 1. 机器学习 = 基于数据的建模，是新编程范式；深度学习是"学习数据表示"，
    机器学习相对称为浅层学习。

 2. 训练误差最小时测试误差不一定最小；理想模型是**测试误差最小**的模型。

 3. 泛化误差 = 偏差² + 方差 + 随机误差；复杂度↑→偏差↓、方差↑。

 4. 模型选择遵循奥卡姆剃刀：训练误差可接受时，选更简单的模型。

 5. 过拟合的表现：训练误差小、测试误差大。

 6. K 折交叉验证是最常用的泛化误差估计方法。

 7. 朴素贝叶斯假设输入变量**条件独立**，文本分类表现好（配合 TF-IDF）。

 8. 1-近邻法的错判率不超过贝叶斯分类器错判率的 **2 倍**。

 9. KNN 不适用于高维（维灾难），必须先降维。

10. 决策树叶节点 ↔ 矩形区域；树深度是模型复杂度的度量。

11. CART 是二叉树，用贪心算法递归二分；后剪枝用最小代价复杂度剪枝（MCCP）。

12. 自举法中约 **36.8%** 的样本不出现在自举样本中（0.632 自举法）。

13. Bagging 降低方差；随机森林通过**降低树间相关性**进一步降方差。

14. AdaBoost 通过增大误分样本权重，让后续弱模型专注难样本；
    要求每个弱模型 err < 0.5。

15. GBDT 在平方损失下，伪响应变量就是**当前残差**。

16. XGBoost 用二阶泰勒展开 + 结构分数最小求解决策树，收敛最快（约20轮）。

17. 感知机的加法器在分类中对应**超平面**，权重迭代 = 超平面向错误点移动。

18. 隐藏节点的作用：实现**非线性样本的线性化变换**。

19. 小批量 SGD（Mini-Batch）是实践中的首选更新策略。

20. SVM 选择**最大边界**超平面；超平面**仅由支持向量**决定（鲁棒性来源）。

21. 参数 C 平衡误差与复杂度：C 大→边界窄、易过拟合；C 小→边界宽、误差高。

22. 核函数的价值：无需显式升维即可完成高维内积运算（核技巧）。

23. SVR 用 ε-"管道"实现回归，管道内残差忽略不计，兼顾鲁棒性与精度。

24. L1 正则化（Lasso）因约束域有尖角，更可能使系数**严格为 0** → 特征选择。

25. PCA 求相关系数矩阵的**特征值与特征向量**，按累计方差贡献率 > 80% 选主成分。

26. 因子分析中 aij 是变量与因子的相关系数，aij² 是方差解释度；
    变量共同度 hi² 高说明信息保留好。

27. 系统聚类可一次性给出 K=1..N 的所有聚类解，便于确定 K。

28. DBSCAN 能发现**任意形状**的簇并识别**噪声点**，但对参数敏感。

29. Mean-Shift 无需指定 K，但聚类数受核宽 h 影响（h 越小 K 越大）。

30. BIRCH 用 CF 树只存聚类特征不存原始数据，适合**内存受限的大数据在线聚类**。

附录 C  算法选择决策索引
================================================================================

【按任务类型选】
  数值型输出（回归）：
    线性回归 / 回归树 / SVR / 梯度提升回归树
  分类型输出（分类）：
    Logistic 回归 / 朴素贝叶斯 / KNN / 决策树 / SVM / 神经网络
  无标签（聚类）：
    球形簇→K-均值；任意形状/有噪声→DBSCAN；需层次→系统聚类；
    大数据→BIRCH；概率软聚类→EM

【按数据特点选】
  维度高、变量多        → 先做特征选择/提取（第9、10章）再建模
  维度高、样本少        → SVM（第8章）、Lasso（第9章）
  非线性边界明显        → 决策树 / SVM+核函数 / 神经网络 / KNN（低维时）
  需要高预测精度        → 集成学习：随机森林 / GBDT / XGBoost（第6章）
  需要可解释性          → 决策树 / Logistic 回归 / 线性回归
  文本数据              → 朴素贝叶斯 + TF-IDF
  单模型方差大          → Bagging / 随机森林
  单模型偏差大          → Boosting（AdaBoost / GBDT / XGBoost）
  有离群点/噪声         → DBSCAN（能自动识别）、SVM（软间隔）
  类别极不平衡          → 注意用 ROC/AUC、P-R 曲线评价，而非准确率

【调参优先级提示】
  决策树      ：最大树深度、最小样本量、最小异质性下降值
  随机森林    ：树棵数 B、随机选变量数 m（常取 √p 或 log₂p）
  AdaBoost    ：迭代次数 B（弱模型数）
  GBDT        ：迭代次数 B、学习率 ρ、树深度
  XGBoost     ：迭代次数、学习率、树深度、α（L2）、γ（最小分裂损失）
  SVM         ：惩罚参数 C、核函数类型、核参数（如 RBF 的 γ）
  SVR         ：C、ε
  神经网络    ：隐藏层数与节点数、激活函数（ReLU 常用）、学习率 ρ、
                批量大小 n、训练周期数
  Lasso/Ridge ：收缩参数 α
  KNN         ：K 值、距离度量、是否加权
  DBSCAN      ：ε、minPts
  Mean-Shift  ：核宽 h
  BIRCH       ：分枝因子 B、阈值 T
