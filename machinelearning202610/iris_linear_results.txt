鸢尾花线性二分类示例 —— 运行输出
====================================================
数据来源 : UCI ML Repository, Iris Data Set (Fisher, 1936)
          本地文件 iris.data（亦可由 sklearn.load_iris() 获取，同源）
样本总数 : n = 150（setosa=50，其余=100）
特征     : 第1列=萼片长(cm)，第2列=萼片宽(cm)；仅用前两维
标签     : setosa -> y=1，其余两类合并 -> y=0
划分     : 训练 105 / 测试 45（比例 7:3，种子=42）
模型     : Fisher 线性判别 LDA（闭式解，线性方法，无迭代）
          g(x) = w^T x + b，当 g(x)>0 判为 setosa
          w = Sw^{-1}(mu1 - mu0),  b = -w^T * (mu1+mu0)/2
----------------------------------------------------
判别系数 : w = [-0.0672, 0.1163],  b = 0.0150
决策边界 : -0.0672*x1 + 0.1163*x2 + 0.0150 = 0
          即 x2 ≈ 0.5774*x1 + -0.1291
训练准确率: 98.10%
测试准确率: 97.78%
----------------------------------------------------
解读     : setosa 在前两维上“近似”而非“完全”线性可分，
          故准确率很高（≈98%）但未达 100%；这源于数据特性，
          不表示线性模型万能。若数据呈明显非线性边界，应
          改用核方法或更复杂模型（见教材第8章 SVM）。
